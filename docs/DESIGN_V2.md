# めだか台帳 v2.0 — 水辺の余白

2026-11-19。全面リデザインの実装仕様。今回の依頼により、旧来の週単位の画面改修範囲を超えて全画面を対象にする。デザインの細部は実装側で判断し、main へのマージは依頼者の承認後とする。

## 体験

無印良品のように装飾を絞った日用品の静けさと、日本の水辺の風景を組み合わせる。特定ブランドのロゴ・図版・画面の複製はしない。「水辺の余白」を主題に、生成り、白、深緑、細い区切り、十分な余白で情報を整理する。

- ホームは日付、季節、静かな水景、現在の飼育状況、記録の入口、今日の確認事項の順。水景はオフラインの SwiftUI Canvas で描く独自の静止画。文字は風景に重ねず別の面に置く。
- 見出しの明朝は軽く、操作と記録はシステム書体。すべて Dynamic Type に追従する。数値は桁をそろえる。
- 背景は生成り、記録の面は白。ダークモードは緑を含んだ墨色。強い影、光沢、装飾のための数字タイルを増やさない。
- 色だけに意味を持たせない。期限超え、状態、選択は必ず文言または記号を併記する。
- 一覧・フォーム・シートには共通の余白、行の面、ボタン、説明を適用する。主要操作は高さ 52pt 以上。文字拡大時は横並びを縦に替える。

## 画面ごとの変更

| 画面 | v2 の構成 | 維持する操作 |
|---|---|---|
| ホーム | 水景の表紙、日付と季節、控えめな集計、記録する、季節の確認、最近の記録 | 採卵、水換え、水温、写真、設定。群の増減は既存の入力画面への選択導線を追加 |
| 容器 | 飼育容器の案内、置き場所別のカード、容器名と群、水換えの状態 | 検索、並べ替え、編集、アーカイブ、移動、写真、作業記録 |
| 系統 | 系統の案内、代表写真またはめだかの絵、系統名・表現・飼育数 | 手動並べ替え、作成、編集、群、血統図、写真、販売 |
| 繁殖 | 親魚セットと育卵中の概要、育卵ロットの目安、親魚セット | 採卵、孵化、親の群、終了、編集 |
| 販売 | 期間、売上を中心とした静かな集計、月別の記録と状態 | 全期間、年別の Pro 制限、CSV、出品文、取消・削除・状態変更 |
| 設定 | データ・Pro の入口、計算・季節・通知を目的別にまとめる | バックアップ、CSV、サンプル、購入・復元、設定値、用語・規約 |
| 詳細と入力 | 共通の白い面と余白、説明つきの入力見出し、下側の保存 | 入力項目・既定値・検証・保存・取り消しを維持 |
| 初回案内・Pro | 水景を共有し、ページの目的と購入条件を読みやすくする | 3ページ、あとで、サンプル、商品価格・復元・購入結果 |

## 変更しない契約

`SchemaV1`、`ModelStore`、Bundle ID、App Group、保存先、設定キー、バックアップ形式、Domain の集計と匹数の台帳、StoreKit の商品と権利判定、Free の上限を維持する。データ移行は発生しない。既存の写真はサムネイルを一覧に使う。追加の通信・SDK・権限は導入しない。v2.0 は今回のデザイン版を指し、ストアの公開バージョンはこの PR では変更しない。

## 検証

- GitHub Actions の既存 macOS / Xcode 26 環境でビルドと全単体テストを実行する。Swift の警告も CI の既存検査対象。
- 実際の iOS Simulator の UI テストで主要画面、入力画面、空状態、ライト・ダーク、拡大文字を撮影する。PR のスクリーンショットコメントに掲載する。
- v2 の UI テストではタブ・画面・保存導線の存在を assertion で確認し、取得できない画面を黙ってスキップしない。
- 既存のバックアップ往復、CountLedger、FreeLimits、ProStore、繁殖・販売・群の操作テストを全件実行する。
- 実機固有のカメラ、通知、購入・復元、ファイル共有の受け入れ手順を PR に残す。
