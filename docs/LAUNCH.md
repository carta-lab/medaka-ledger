## 2. 名称の考え方

検索で見つかることが最優先である。
利用者はストアで「メダカ」「めだか」と打つ。
アプリ名かサブタイトルに「めだか」が入っていなければ検索に出ない。
造語のブランド名を付けるなら、サブタイトルで「めだか」と用途を補う。

## 3. ストア掲載（下書き）

タイトル（30文字以内）：めだか台帳

サブタイトル（30文字以内）：改良メダカの繁殖と系統と販売を記録

キーワード（100文字以内、カンマ区切り）：
メダカ,めだか,改良メダカ,飼育,繁殖,系統,累代,採卵,孵化,選別,ブリーダー,販売,台帳,水換え,親魚

説明文（冒頭の3行が一覧で見える）：

```
改良メダカを増やして売る人のための台帳です。
どの容器に、どの系統の何世代目が、何匹いるか。いつ採卵して、いつ孵るか。どう選別して、いくらで売れたか。
手帳やホワイトボードに散らばっていた記録が、ひとつにつながります。

できること
・容器ごとに今いる群と、最後の水換えからの日数が見える
・系統ごとに世代（入手、F1、F2…）を追い、血統図で親をさかのぼれる
・親魚セットから採卵を記録すると、積算温度で孵化予定日が出る
・孵化を記録すると、次の世代の群が自動で作られる
・選別の残し数と弾き数、行き先を残せる
・販売を記録して、月別の売上、手数料、送料、純額を集計
・写真を群や容器や系統に付けて、世代順に見返せる
・バックアップはファイルに書き出して、機種変更でも引き継げる

アカウント登録は不要です。データは端末の中にだけ保存され、外部に送信しません。

Proは買い切りです。容器と系統と親魚セットの上限がなくなり、血統図の全世代表示、年別集計、販売のCSV書き出し、出品文テンプレが使えます。
```

スクリーンショット（6枚、iPhone 6.9インチと6.5インチ）：

1. ホーム（産卵期、孵化予定と育卵中が並ぶ）
2. 容器一覧（置き場所ごとのグリッド）
3. 群詳細（タイムライン）
4. 採卵記録と孵化予定日
5. 血統図（3世代、交配あり）
6. 販売台帳（月別集計）

審査担当への注記：
- サンプルデータの読み込み手順。
- Proは非消耗型1点で、復元ボタンの場所。
- 通信はStoreKitのみ。アカウントなし。

プライバシーの申告（App Privacy）：データを収集しない。

改良メダカの繁殖と販売の記録アプリをiPhone向けに作っています。

## 6. 法務、税務、運用の確認事項

- 勤務先の副業規定を、収益が出る前に確認する。
- ストア説明の末尾に「記録の道具です。税務や法務の判断はしません」の一行を入れる（`DECISIONS.md` I）。
- 個人の開発者アカウントではApp Storeに本名が表示される。表示名を変えたい場合は法人か屋号の扱いを事前に調べる。
- アプリの売上はApple経由で入金され、雑所得または事業所得として申告する。経費（開発者登録料、端末、通信費の按分）の領収書を残す。
- プライバシーポリシーには、データを端末内にだけ保存すること、購入者メモを含め外部に送信しないこと、StoreKit以外の通信をしないことを書く。
- サポートの連絡先はメールアドレス一つにし、ストアのサポートURLに載せる。
- 利用規約はAppleの標準EULAを使う。

## 8. 公開後の判断

2027年7月1日に `PRD.md` 8章の指標を確認する。

- Pro購入が100本に届かなくても、7日後の再起動率が35%を超えていれば、使われているが買う理由が弱いと判断し、Proの内容（血統図、CSV、出品文）の見せ方を直す。
- 再起動率が20%を下回る場合は、記録の手間が実態に合っていないと判断し、βテスターに再度の聞き取りをしてから機能を削る。
- 検索順位が10位以下なら、タイトルとサブタイトルの語を入れ替えて2週間ごとに比べる。
