# 改良メダカの繁殖と販売の基礎知識

このアプリが扱う対象を、実装者が迷わない粒度で説明する。
用語はここで定義したものをアプリ内の文言、データモデル、コードのコメントで共通に使う。

## 改良メダカという趣味

**改良メダカ**は、野生のメダカから人為的な交配で作られた観賞用の品種群を指す。
体色、ラメ、ヒレの形、体型といった**表現**（見た目の特徴）が売り物で、新しい表現を固定した系統は高値で取引される。
飼育は屋外の容器で行うことが多く、水槽や照明やヒーターを必要としない。
このため初期費用が小さく、繁殖も容易で、飼育者の一部は増えた個体を売って副収入にしている。

飼育者が困っているのは、個体数が増えて容器が数十に達したときの記録である。
どの容器にどの系統の何世代目がいるか、どの親から採った卵がどの容器で育っているか、いつ選別したか、いくらで売ったかを、多くの人は手帳、ホワイトボード、表計算で管理している。
このアプリは、その台帳を置き換える。

## 用語

- **品種**：楊貴妃、幹之（みゆき）、三色、ブラックダイヤ、オロチのように、表現の組み合わせに付けられた呼び名。品種名は作出者や販売店ごとに揺れがあり、同じ名前でも質が違う。
- **系統**：特定の作出者や購入元から入手した血統。アプリでは「品種名＋入手元や呼び名」で一つの系統とする。例：「楊貴妃（〇〇めだか2026春購入）」。品種より細かく、個体より粗い単位。
- **累代**：親から子、子から孫へと世代を重ねること。入手した世代を起点に**F1**、**F2**と数える。アプリでは入手個体を第0世代（表示は「入手」）とし、その子をF1とする。
- **固定率**：ある表現が子に現れる割合。固定率の高い系統ほど価値が高い。アプリでは数値を自動計算せず、選別記録の残し数と弾き数から利用者が読み取る。
- **親魚**：採卵に使う成魚。**ペア**（雄1雌1）または**トリオ**（雄1雌2）で組むことが多く、雄2雌3のような組み方もある。異なる系統を掛け合わせる**交配**も行われる。
- **採卵**：雌が産んで産卵床（人工産卵床やホテイアオイ）に付いた卵を回収すること。産卵期は毎日のように採卵する。
- **産卵期**：水温がおおむね18℃を超え、日照時間が13時間前後を超える時期。多くの地域で4月から9月まで。冬は産卵しない。
- **積算温度**：卵が孵化するまでに必要な温度の累積。改良メダカの飼育では「水温（℃）×日数が約250に達すると孵化する」という目安が広く使われる。25℃なら約10日、20℃なら約13日。
- **針子**：孵化直後から2週間程度の稚魚。体長5ミリ前後で、餌切れと水質悪化に弱い。
- **稚魚、若魚、成魚**：針子の後、1センチ前後を稚魚、2センチ前後を若魚、3センチ前後で産卵可能になった個体を成魚と呼ぶ。境界は厳密でない。孵化から成魚まで2から3か月。
- **選別**：育った子の中から、表現や体型の良い個体を残し、残りを**弾く**こと。1回目は1センチ前後で体型と奇形、2回目は2センチ前後で色やラメ、3回目は成魚で親魚候補を選ぶ、という3段階が典型。弾いた個体は餌用、格安販売、別容器での飼育、処分のいずれかになる。
- **容器**：飼育に使う入れ物。NVボックス（13リットル、22リットルが定番）、トロ舟（40、60、80リットル）、発泡スチロール箱、プラ舟、睡蓮鉢、水槽。屋外に数十個並べる人が多く、番号やラベルで識別している。
- **グリーンウォーター**：植物プランクトンで緑色になった飼育水。針子の餌になるため、針子の容器で意図的に作る。
- **水換え**：飼育水の一部または全部を入れ替える作業。夏は週1回程度、冬はほぼ行わない。足し水と区別する。
- **薬浴**：病気の個体や卵を薬剤（メチレンブルーなど）の入った水に入れること。
- **越冬**：屋外の容器で冬を越させること。採卵も選別も止まり、記録は水温と生存確認が中心になる。

## 一年の流れ

1. 3月から4月：越冬明け。親魚候補を選び、容器を立ち上げ、系統ごとに親魚セットを組む。
2. 4月から9月：産卵期。採卵、卵の管理、孵化、針子の育成、選別が毎日のように重なる。容器の数が最も増える。
3. 6月から10月：春に生まれた子が成魚になり、販売が本格化する。即売会やイベントも多い。
4. 10月から2月：越冬。販売は細り、翌年の親魚選びと系統の整理をする。

アプリの需要は3月から6月に集中する。
公開は産卵期の前に済ませる必要がある。

## 繁殖の記録単位

繁殖は次の単位で進む。
データモデルはこの流れをそのまま写す。

```
系統 ─┬─ 群（入手個体、第0世代）
      │     └─ 親魚セット（雄の群 × 雌の群、容器、期間）
      │            └─ 採卵ロット（採卵日、卵数、水温、孵化予定日）
      │                   └─ 群（F1、孵化日、針子の容器）
      │                          ├─ 選別（残し数、弾き数、基準）
      │                          ├─ 移動、分割（容器の変更）
      │                          ├─ 増減（死亡、計数修正）
      │                          └─ 販売（匹、ペア、卵、価格、販路）
      └─ 群（F1から親魚セットへ、以下繰り返し）
```

**群**は「同じ系統、同じ世代で、同じ容器にいる個体の集まり」である。
個体を一匹ずつ登録する設計は採らない。
飼育者は数十匹から数百匹を容器単位で扱っていて、一匹ずつ識別しているのは親魚候補と高額個体だけだからである。
親魚候補や高額個体は、匹数の少ない群として扱えば個体に近い記録ができる。

**血統**は、群から採卵ロットをたどり、親魚セットの雄の群と雌の群へさかのぼることで得られる。
親魚セットの雄と雌が別の系統なら交配であり、子の群は新しい系統名（例：「楊貴妃×幹之」）を持つ。

## 販売の実態

- 販路：ヤフオク（生体の出品が多い）、自分のネットショップ（BASE、STORESなど）、即売会やイベント、専門店への委託、XやInstagramのDMによる直接取引。メルカリは生き物の出品が禁止されており、卵も規約の確認が要る。
- 売り方：匹単位、ペア、トリオ、卵（10個単位など）、稚魚のまとめ売り。
- 価格：ヒメダカは1匹数十円だが、新しい表現の系統は1匹数千円から数万円、ペアで10万円を超える例もある。
- 発送：ゆうパックなどで活魚を送る。死着保証の有無を出品文に書く。
- 出品文に書く定番の項目：品種名、系統や作出者、世代、匹数と雌雄、サイズ、孵化時期、親の表現、飼育環境（屋外か室内か）、死着保証、注意事項。

## 法令と倫理

- 動物愛護管理法が定める第一種動物取扱業の登録は、哺乳類、鳥類、爬虫類が対象で、魚類は対象外である。メダカの販売に登録は要らない。
- 販売で得た所得に税がかかる場合がある。申告の要否と額は利用者が税務署や税理士に確かめる。アプリは税の判断も計算もしない。
- 遺伝子組換えで光るメダカの飼育や譲渡はカルタヘナ法で禁止されている。アプリで扱う対象にしない。
- 改良メダカを川や池に放すと在来メダカと交雑して遺伝子汚染を起こす。弾いた個体の処分先に「放流」は用意しない。

## アプリが扱わないこと

- 個体識別（一匹ずつのID付与）。群の匹数で足りる。
- 自動の固定率計算や表現の判定。写真から表現を判定する機能も作らない。
- 餌やりの記録。毎日複数回あり、記録の価値が低い。
- 飼育者同士の交流や相場情報。サーバーを持たない方針と合わない。
